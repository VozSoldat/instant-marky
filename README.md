# InstantMarky - Publish your markdown instantly

Just write down your markdown and let the app render it for you. No database needed.

## How does it work?

InstantMarky is a simple static website that keeps your markdown inside the URL and let you preview it.

## How to use it?

Write your markdown here ([instant-marky.netlify.app](https://instant-marky.netlify.app)) and share the link.
